
# 🌱 YeşilYaşam

Doğa ve çevre bilincini artırmayı amaçlayan modern, responsive bir web sitesi.

## 📌 Proje hakkında

YeşilYaşam, sürdürülebilir yaşam ve çevre dostu alışkanlıklar hakkında
bilgi veren, HTML ve CSS ile hazırlanmış örnek bir web projesidir.

## ✨ Özellikler

- Modern ve sade tasarım
- Telefon, tablet ve bilgisayar uyumluluğu
- Doğa dostu yaşam önerileri
- Kart tabanlı içerik alanları
- Sayfa içi gezinme bağlantıları
- Harici kütüphane gerektirmeyen yapı

## 🛠️ Kullanılan teknolojiler

- HTML5
- CSS3

## 🚀 Nasıl çalıştırılır?

1. Bu projeyi bilgisayarına indir veya klonla.
2. `index.html` dosyasını tarayıcıda aç.
3. Web sitesini kullanmaya başla.

## 📁 Dosya yapısı

```text
yesilyasam-web/
├── index.html
├── style.css
└── README.md
```
